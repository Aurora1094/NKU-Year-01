## 课程与学习建议

### AMTD0033 高等数学 AI
- 当时基本都在跟老师进度，但 **2024 年难度上升显著**。  
- 个人体感：只跟进度效果一般，**需要多刷题**来提升熟练度与应试能力。

### AMTD0033 高等数学 AII
- 第二学期前期 **快速过完知识点**，之后开始集中刷题。
- 刷题来源（仅供参考）：
  - 考研竞赛凯哥
  - 仓库：NKU / TJU / SEU 真题
  - B站：WHU 真题
- 个人备注：
  - **SEU 小题**比较能拓展思路  
  - **NKU（2023之前）/ TJU / WHU**难度偏低一些，更适合练手感与打基础

### APIN0014 线性代数
- 2024、2025 考试相对常规。
- 推荐路线：
  1. **梨米特线性代数**速通
  2. 再看 **黄丽娟线性代数习题课**进行刷题巩固与查缺补漏

### ELEC0203 大学物理
- 大部分为高中知识延伸与整合。
- 建议：**按题型总结套路**，形成自己的“题型-方法”清单，效率会更高。

### COSC0002/COSC0039 高级语言程序设计 2-1/2-2
- 上机：平时要多练习，**保持手感**很关键。
- 笔试：重点关注（体感更难“临时抱佛脚”）。
- 暂时没找到特别好的方法，个人建议：
  - **PPT 认真过两遍**
  - 总结常见易错点

### COSC0012 概率论与数理统计
- 内容与高中概率 + 微积分衔接较多。
- 刷一遍吉米多维奇应对考试会很简单。
- 建议先把关键概念（随机变量、分布、期望方差、常见分布、极限定理等）捋清，再刷题巩固。
